# Bytewise

Computer science, compiled for humans. Every topic in the UT Dallas BS Computer Science core, from CS 1337 through CS 4384 Automata Theory, taught as:

- **read**: a short lesson with the exam tricks built in
- **trace**: a worked example you step through
- **run**: endless fresh, auto-checked problems

Plus 15 interactive visualizers (code tracer, sorting race, BST, heap, graph search, hashing, K-maps, DFA simulator, CPU scheduling, page replacement, MIPS pipeline, and more) and a timed exam simulator for each course.

Static site: open `index.html` or serve the folder. No build step.
